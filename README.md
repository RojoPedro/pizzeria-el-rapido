# Pizzeria El Rapido — Frontend & Admin CMS

Customer-facing website and integrated administration CMS for **Pizzeria El Rapido**, built to manage the menu, ingredients, and visibility ordering through the companion [`elrapido-backend`](https://github.com/RojoPedro/elrapido-backend) API.

## Features

- Public menu showcase with responsive mobile layout
- Admin dashboard (`src/admin/`) for menu items, ingredient management, and ordering
- Built-in SPA routing configuration for Vercel (`vercel.json`)

## Tech Stack

- **React** + **TypeScript** + **Vite**
- **Tailwind CSS** + **shadcn/ui** (Radix UI)

## Local Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
